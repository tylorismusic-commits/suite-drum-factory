Why it is a system

One surface. No tab archaeology.

The bundle is not five unrelated downloads. It is one build graph, one installer and one surface that knows where the inserts live.

The surface controls the channel

Eight strips, insert pages and a mix bus in one window. Suite Channel Plus is the strip underneath, so the surface moves real controls rather than a remote mock-up.

The peer bus joins the pieces

Suite Control and the inserts talk over a peer bus. Install all five together so the surface, inserts and mix bus agree on the same session.

Pinned and tested together

All five come from the same pinned commits and are tested as a set. No version roulette, no “which channel strip goes with which bus” after an update.

The installer backs up an existing installation automatically. ./install.sh --uninstall removes exactly what it installed.

Good questions

Before you install.

It is a Linux bundle, it is open source, and the refund window is real.

Is this an official SSL plug-in?

No. Suite Control is an SSL-style mix-bus workflow — compressor, EQ, summing colour and limiter — built as an original open-source plug-in. It is not affiliated with or endorsed by SSL.

Do I need all five plug-ins?

For the full console workflow, yes. Suite Control and the inserts communicate over a peer bus, so the bundle is designed to be installed as a set. You can still use individual pieces, but the surface expects its matching channel and inserts.

Which hosts are supported?

Linux x86_64 with a CLAP host such as REAPER or Bitwig, or an LV2 host such as REAPER or Ardour. The bundle includes LV2 and CLAP builds. Windows and macOS are not part of this release.

If it is GPL, why buy it?

The source is public and you can build all five yourself. The bundle saves you the build, pinned-version matching, packaging and installer work. Buying it supports the time that goes into maintaining the set.

What happens on updates?

1.x updates are included. Download the latest bundle from your Gumroad library and run the installer again; existing installations are backed up automatically.

What if it does not work for me?

There is a 14-day refund window, no questions asked. Email the address on the product page and it will be sorted.
